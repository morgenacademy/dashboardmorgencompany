# Dashboard Morgen Company

Een eenvoudig intern dashboard voor handmatige project-, omzet- en liquiditeitsplanning.

## Wat zit erin

- Handmatige invoer van projecten
- Handmatige invoer van terugkerende kosten
- Overzicht per maand voor Karin en Harmen
- Lokale opslag in de browser

## Bestanden

- `index.html` bevat de pagina-opbouw
- `styles.css` bevat de styling
- `app.js` bevat de invoerlogica en maandberekeningen

## Lokaal openen

Open `index.html` in de browser.

## Eerste vervolgstappen

- GitHub koppelen
- Een eenvoudige deploy instellen
- Later eventueel centrale dataopslag toevoegen
